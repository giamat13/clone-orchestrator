# MCP Web Clone

- Source: https://github.com/ericshang98/Perfect-Web-Clone-IDE (MIT), pinned commit 01f3aff. The README title is "Perfect Web Clone IDE".
- Install: Python venv, `pip install -r requirements.txt`, `playwright install`, then register the server with `claude mcp add`. Never hand-edit `~/.claude/settings.json`.
- Upstream requirements have lower bounds only. Record the resolved versions after install.
- Use for capturing a live page (DOM, styles, assets) as input to the build step.

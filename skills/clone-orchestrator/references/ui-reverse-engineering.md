# UI Reverse Engineering (ui-clone-skills)

- Source: https://github.com/voidmatcha/ui-clone-skills (Apache-2.0), pinned commit c6dacc7, plugin version 0.8.16.
- Install: clone locally, `claude plugin marketplace add <path>`, `claude plugin install ui-clone-skills@voidmatcha`.
- Needs `uv` and Python 3.11+.
- Works on LIVE URLs only. It extracts CSS and animation parameters from JS bundles and verifies with AE/SSIM diff. It does NOT accept screenshots or video.
- Skills: ui-reverse-engineering, ui-capture, visual-debug.

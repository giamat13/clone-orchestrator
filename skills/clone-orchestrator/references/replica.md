# Replica Skill

- Source: https://github.com/Jakeschincariol/replica-skill (MIT), pinned commit 77c9436.
- Installed as `~/.claude/skills/replica-*`.
- Pipeline: recon -> architect -> design -> build -> backend -> test -> diff -> entrepreneur -> brand -> launch -> deploy.
- Invoke with `/replica-recon` first. Later steps read the recon map it writes.
- Helper scripts need Python 3.8+. On Windows use `python`, not `python3`.
- Rewrites everything fresh; never copy the original's code, assets or copy.
- Limit: works from public pages, screenshots, store listings and the user's own account. Not a pixel-exact screenshot-to-code tool.

# Android reverse engineering skill

- Source: https://github.com/SimoneAvogadro/android-reverse-engineering-skill (Apache-2.0), pinned tag v1.7.0.
- Install: clone locally (on Windows use `git -c core.longpaths=true clone`), then install as a plugin.
- Needs Java 17+ and `jadx` on PATH.
- Only for apps the user owns or is permitted to analyze.
- Pair with REA for native libraries and runtime inspection.
